# Метрики демонстрационного примера

Метрики получены для обезличенного входного артефакта и результата, созданного
текущим публичным интерфейсом проекта с сохранением поддерживаемых выводов:

```bash
uv run jupyter-cleaner convert examples/example.ipynb \
    --keep-outputs \
    --output examples/example.md
```

## Размер файлов

- Исходный файл: `examples/example.ipynb`.
- Результат: `examples/example.md`.
- Исходный размер: **367 073 байта** (358,47 КиБ).
- Итоговый размер: **39 104 байта** (38,19 КиБ).
- Удалено: **327 969 байт**.
- Уменьшение: **89,34707810163101 %** (89,3 % при округлении до одного знака,
  как в выводе CLI).

Размеры независимо проверены через `Path.stat().st_size`. Процент рассчитан как
`(367073 - 39104) / 367073 * 100`; исходные измерения в байтах не округлены.
